# Runware-Produktion 2026-11-09 — restliche 72 Figuren

## Umfang

- 72 Figuren (alle Fraktionen außer Machina), je 8 Walk- und 8 Action-Frames.
- **1152 Rohframes**, 0 Fehlschläge.
- Modell: `alibaba:qwen-image-edit@2511` über Runware, 512×512, Auto-Referenzen:
  - Biped/Hover: Posen-Guide (1 Referenz)
  - Quadruped/Serpentine/Tracked/Avian/Arachnid/Swarm: Identität + Posen-Guide (2 Referenzen)
- Guides aus den vorhandenen Sheets: `artifacts/design-rest/guides/<id>/`.

## Nachbereitung

1. Chroma-Freistellung auf dem uniformen grauen Hintergrund, Innenflächen per `binary_fill_holes` geschlossen.
2. Alpha-Splitter entfernt (größte zusammenhängende Fläche; Schwarm behält alle).
3. Upscale 512 → 1024 (Lanczos), Normalisierung auf Grundlinie y=960.
4. Packen mit `pack.py` zu 144 Sheets (1024×512 RGBA WebP).
5. Übernahme nach `src/client/assets/sprite-sheets/<fraktion>/`; Originale unter `artifacts/design-rest/original-rest/`.

## Offene Qualitätsgrenzen

- `npm run check:sprites` meldet 64 Hinweise „Zerfasert“ (4–6 Flächen pro Zelle). Das sind überwiegend abgetrennte Flammen/Schweife und kleine Ränder, keine leeren Zellen; die Ampel steht deshalb auf Rot.
- 512er Quellen sind hochskaliert; für native 1024er Schärfe wäre ein zweiter Lauf mit 1024×1024 und ca. 24–27 USD nötig.
- Einzelne Figuren führen Requisiten aus dem alten Guide mit (z. B. Stab bei Dark-Matter-Witch); das Spiel rendert Waffen separat.

```bash
  --characters <ids> --animation walk --width 512 --height 512 --refs auto \
  --out artifacts/design-rest/runware-rest-walk --execute

  artifacts/design-rest/runware-rest-walk walk

python3 tools/design-rest/runware-specs.py walk --approve <fraktionen>
```
